# Divergence from upstream

This fork changes upstream `gearmulator`. Every change that is not a candidate
for an upstream pull request is a divergence, and every divergence gets a row in
the table below.

## The rules

1. One row for each divergence.
2. Add a new row at the end of the table. Do not change a row that another
   change added.
3. A row names the file, the reason for the divergence, and if the divergence
   can be removed.
4. A row that says a divergence can be removed also gives the condition that
   permits the removal.

| `xcodeversion.cmake` | **Two characters on one line.** `xcodeversion.cmake:10` gains quotes around its last argument, `version_match ${xcodebuild_version}` becoming `version_match "${xcodebuild_version}"`. | `hdi08.h`, `hdi08.cpp` in the `source/mc68k` submodule (the fork `axiomantic/mc68k`, pinned at `5df52aa`) | **Five lines. `mc68k::Hdi08::m_rxEmptyCallback` is never initialised.** `Hdi08::Hdi08()` at `hdi08.cpp:11-20` initialises FOUR of the class's five callbacks — `m_writeTxCallback`, `m_writeIrqCallback`, `m_readIsrCallback` and `m_initHdi08Callback`, each through a setter that substitutes a no-op when the argument is null.
