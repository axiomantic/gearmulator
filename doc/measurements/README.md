# Measurement logs

Output from `zz_audio_out`, one file per arm, from the runs cited in the
findings corpus.

The instrument's per-write bus trace is stripped. It was 99.97% of the
output -- 155,571 of 155,620 lines in one arm, against 49 lines of actual
measurement -- and none of the corpus's figures come from it. Re-run the
instrument to regenerate it if a question needs the trace.
